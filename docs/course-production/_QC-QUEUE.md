# QC QUEUE — Codex → Claude video-QC handoff

**Purpose:** Codex produces lessons but NEVER declares one finished on its own. It renders, then hands the cut to a Claude QC tab here. Claude runs the `custom-video-qc` dense-sweep, writes a verdict, and Codex only finishes on **QC: PASS**.

## Protocol
1. **Codex** finishes a render → copies it to `course-assets/review-lesson<X>/LESSON-<X>-vN.mp4` → appends a row below with status `AWAITING-QC` → then **STOPS and waits** (does not tell Jarrad it's done).
2. **Claude QC tab** reads this file, picks the oldest `AWAITING-QC` row, runs the QC harness on that render, writes findings to `course-assets/review-lesson<X>/QC-REPORT-vN.md`, and flips the row to `PASS` or `FAIL` (with a one-line summary + the report path).
3. **Codex** polls this file for its row. On `FAIL` → reads the report, fixes every item at the source, re-renders as `vN+1`, appends a new `AWAITING-QC` row. On `PASS` → only now may it mark the lesson delivered to Jarrad.
4. **Promoted renders are IMMUTABLE (added 2026-07-08 after the 18B v6 in-place overwrite invalidated a QC pass):** never overwrite a promoted `LESSON-<X>-vN.mp4`. Any changed build = `vN+1`, always.
5. **Mobile-review delivery (Jarrad 2026-07-10, PERMANENT):** every asset that reaches "awaiting Jarrad" gets a **COPY** in the Drive folder **"BMH Course — NEEDS JARRAD APPROVAL"** (id `1-V99TonVTsVtMerYtOHgSPqPMpbXuwCN`), in a numbered lesson subfolder `NN — <lesson> — PENDING JARRAD APPROVAL`. COPY only — never move/delete the working or archive original (big files via the Drive desktop mount). After his verdict, rename the subfolder to `… — APPROVED` / `… — REJECTED` immediately so status is never ambiguous.

## QC bar (what Claude checks — the custom-video-qc skill)
- **Whole-clip dense sweep** of every animation beat at 0.5s cadence (NOT just start/mid/end) — a duplicate-character clone hid in the back third of a landlord clip and only a full sweep caught it.
- Per-beat proof frames vs standing rules: canonical blue `#62b3f3`, no ambient doodles, no clipped art, correct Andrea mode, on-brand style (no restyle/shading/proportion drift).
- Audio: no dead gaps inside beats, loudness mean −20±6 dB, 1.0s inter-beat pauses present.
- Labels word-timed; BMH badge on the opening beat; logos hand-lettered (not pasted vector).
- Any FAIL = the whole lesson is FAIL until fixed. Never pass a render with an outstanding FAIL.
