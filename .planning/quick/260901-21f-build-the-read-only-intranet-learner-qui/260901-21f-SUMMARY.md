# Internal intranet learner quiz-summary API summary

## Delivered

- Added the read-only `GET /api/internal/intranet/learners/[email]/quiz-summary` route for BMH me.
- Added fail-closed bearer authentication through the server-only `INTRANET_SERVICE_TOKEN`. Unset, placeholder, whitespace, short, malformed, and incorrect tokens are rejected before database access. Supplied credentials are compared through fixed-length SHA-256 digests with `timingSafeEqual`.
- Kept service-role access behind the credential guard and limited the route to reads.
- Scoped the final quiz to the published canonical `bmh-employee-training-v1` course. The route fails closed on duplicate canonical courses or an ambiguous terminal quiz.
- Counts all completed attempts with an exact database count. Best score and latest completion use separate one-row queries. Every attempt query is scoped by learner, quiz, and lesson.
- Returns the exact required fields and applies the inclusive 85-point passing boundary.
- Added no-store response headers and allowed only the new internally authenticated route prefix through the session middleware.
